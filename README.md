# BI Eleições 2020 — São Paulo

Projeto de análise de dados das eleições de 2020 no estado de São Paulo.

## Objetivo

Construir uma solução completa de Business Intelligence para analisar as Eleições Municipais de 2020 no Estado de São Paulo.

## Fonte dos dados

Os dados serão obtidos no [Portal de Dados Abertos do TSE](https://dadosabertos.tse.jus.br/).

## Tecnologias previstas

- Python
- Pandas
- NumPy
- Jupyter
- PostgreSQL
- SQL
- Power BI
- DAX

## Gestão

O projeto é gerenciado no Jira, no projeto **ELEICOES**.

## Metodologia

Scrum com Sprints semanais.

## Estrutura do projeto

```text
docs/         Documentação do projeto
data/         Dados locais brutos e processados (não versionados)
notebooks/    Análises exploratórias em Jupyter
src/          Código de extração, transformação e carga
sql/          Scripts SQL de staging, data mart e consultas
powerbi/      Artefatos do Power BI
tests/        Testes automatizados
```

> A estrutura inicial não contém datasets. Consulte a documentação antes de iniciar uma nova etapa do projeto.
